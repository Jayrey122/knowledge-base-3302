# Disciplinary Case Studies

Disciplinary case studies show how gamification and simulation tools tools can be used in different areas of high school mathematics. Each activity uses math skills along with game like features such as challenges, missions, levels, teamwork, feedback, and progress. Simulations make the math easier to explore because students can change values, move objects, create graphs, and see results right away.

This sections looks at examples of gamified math activities that could be used in Algebra, Geometry, Functions, Statistics, and Precalculus. A student will move through an algebra challenge path by solving equations, work with a group to complete a geometry escape mission, or use a graphing tool to create a function that matches a target graph. These activities can make math feel more active because students are solving problems, testing ideas, and explaining their thinking or reasoning as they work toward a goal.
