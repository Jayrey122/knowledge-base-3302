# Function Quest Levels

Function quest levels combine graphing simulations with a series of game like challenges. Students begin with a parent function and work through levels by changing parts of an equations, Each level can focus on a different transformation such as moving a graph, stretching it, shrinking it, or reflecting it across an axis.

## Starting With Parent Functions

A parent function is the basic form of a function before it has been changed. Students may start with \(y=x^2\), \(y= |x|\), or \(y=\sqrt{x}\). The first level can ask students to identify the shape and main features of the original graph.

## Unlocking Transformations

Later levels can ask students to change the equation and describe what happens. For example students may move a graph up or down, shift it left or right, make it wider or narrower, or reflect it. A student can unlock the next level after explaining the change correctly. 

## Progress Through Understanding

A goal of a function quest is not only to finish a level. Students should understand why the graph changed and what part of the equation caused the transformation. The simulation gives them a way to test an idea while the game structure gives them a clear path to follow.

A function quest may move from identifying a parent function to changing its position, changing its shape, and creating an equation that matches a target graph.
