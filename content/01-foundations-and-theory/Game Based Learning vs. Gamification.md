# Game Based Learning vs. Gamification

Game based learning and gamification are similar, but they are not exactly the same. Game based learning uses a complete game as part of the learning activity. Gamification adds game like features like points, badges, progress bars, or challenges to an activity that is not already a game.

This image compares a complete educational game with a regular learning activity that uses points, badges, and progress tracking.

![A split graphic showing the difference between game based learning and gamification](game-based-learning-vs-gamification.jpeg)

## Game Based Learning

Game based learning happen when students learn by playing a complete game. The game may teach a subject, ask students to solve problems, or let them practice a skill. The game itself is the main learning activity so students learn through the choices and challenges built into the game. 

## Gamification

Gamification does not require a full game. A teacher can take a regular activity like a discussion, project, quiz, or worksheet and add goals, levels, rewards, or progress tracking. These features can make the activity feel more interactive without changing it into a full game. 

## The Main Difference

The biggest difference is that game based learning uses a real game while gamification uses parts of games. Both approaches can make learning more engaging when they are connected to clear learning goals. The important part is that students are still learning and not only trying to earn rewards.
